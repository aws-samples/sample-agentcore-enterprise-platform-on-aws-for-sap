SOP retrieval paths
  • The case's SOP comes whole, with its tolerances and contacts filled in, and names the S3 version it read.
  • Search finds a SOP the agent was not handed. Each hit is a whole SOP, filled in the same way.
  • No one may delete a version, so a run's evidence names the exact text it followed.
Configuration
  • load_sop reads the bucket, not the knowledge base, so it works with search off.
  • knowledge.sop_search (on by default) adds the knowledge base and search_sap_sops.
  • The bucket's policy lets only the /sops route and the pack composer write SOPs.
