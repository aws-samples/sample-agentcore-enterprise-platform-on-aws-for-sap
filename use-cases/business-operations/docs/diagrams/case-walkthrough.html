Case record
  • The Activity tab: every step of every run, every update_case_state call and every human decision.
  • The SOP version each run used, and the SAP reads it made, as evidence.
  • A case closes complete, with or without a SAP write; one the agent cannot settle goes to manual_review_required.
Autonomous write conditions
  • Only to the case's own document (the case document check), and only within the pack's AUTO_WRITE_LIMIT_USD.
  • An approval by a member of the pack's approve_groups lifts the limit for the one write the approver saw, field for field.
  • Above DUAL_APPROVAL_LIMIT_USD, two different approvers choose the same outcome: approving twice yourself is refused.
  • The trigger mode, set for the deployment and for each pack, starts manual: no new case is queued until both are auto. A case worker can still start one.
