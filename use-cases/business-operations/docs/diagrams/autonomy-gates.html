Unattended runs
  • Only when both trigger modes read auto; both start manual, since a fresh deploy would otherwise queue every open exception SAP shows it.
  • Admins set the deployment's on Deployment settings, PUT /deployment/trigger-mode or ops.py trigger-mode set auto, and a pack's on its Overview, PUT /packs/{pack_id}/trigger-mode or --pack.
  • The trigger modes apply to new work only: a run under way finishes, and a person's reply is queued in either mode.
  • The Emergency stop (POST /deployment/stop) stops every run in progress, refuses every start and resume, and keeps both trigger modes at manual until an admin clears it. Both need a reason.
Amount gate inputs
  • The case's amount, in USD, against its pack's limit; a pack that declares no limit has none. No readable amount, or another currency, is refused.
  • A case made from pushed records never writes on its own amount.
  • Above the limit, the only write that passes is the one the approver approved. A pack with no approve_groups lets anyone who can see it approve.
