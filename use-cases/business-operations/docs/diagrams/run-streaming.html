Channel, not response body
  • Whoever started the run, the console watches the channel, so a second tab or a reload picks it up mid-run.
  • A run outlives an API Gateway request by minutes, which is why POST /runs hands it to the invoker and returns.
  • A question (ask) streams the same way, but its grant lets it write nothing; only Process and a resume after a decision may write.
Publish and subscribe permissions
  • Only the runtime's role publishes (IAM); the browser holds no IAM credentials, so it cannot forge an event.
  • Subscribe needs the console's own token, and run_events_auth admits a case channel only on a pack the user may see.
