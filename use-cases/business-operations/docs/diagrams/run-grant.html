What a run grant holds
  • The run id and the app client that may use it.
  • A hash of the grant secret. Only the invoker and the agent hold the secret.
  • The case, and the packs the run may touch.
  • The one write a person approved, if there is one, and who approved it.
  • Whether the run is a rehearsal or a question, which may not change data.
When the run checks refuse a call
  • No grant for the run id, a different app client, a wrong secret, or an expired grant.
  • A rehearsal or a question that tries to change data.
  • A SAP write to a document that is not the case's own (the case document check).
  • A SAP write over the pack's limit that is not the write a person approved.
  • After the run ends: the invoker has deleted the grant, so its secret cannot be used again.
