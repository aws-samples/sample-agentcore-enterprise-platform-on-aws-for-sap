SAP exception handling

SAP access limits

Access row
Operator · layers.sap.access in platform.yaml
The upper limit for the use case: which SAP systems it may read and write through the Gateway, and which systems its own functions call directly.
SAP access claim
Use case author · the use case's code
The app clients, systems and writes the use case says it uses. It must fit inside the access row. The SAP layer refuses every SAP call that no claim covers, and every delete.
Cedar permit
Security engineer · security.cedar
Which app client may call which tool: the reader client reads, the writer client writes. Cedar refuses a call only in ENFORCE mode.
Run checks
Pack admin · the pack's controls
A live run grant, a write only to the case's own document (the case document check), and a write over the limit only after a person approves it.
SAP authorizations
SAP Basis · the roles of the SAP user
SAP checks the roles of the user the server signs in as: the system's service account, or with the obo flow, the person who started the run.
A SAP call goes through only when every box allows it.
